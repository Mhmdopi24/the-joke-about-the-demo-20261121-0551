Bounty: [The joke about the demo](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551)

A tiny, dependency-free Node program that writes one deterministic one-line joke about an AI coding agent and a demo-day crash to `entry.txt`. Run it with `MAKEFUN_OUTPUT_DIR` set (default `/output`) and it creates the directory if needed and always produces the exact same single line.
